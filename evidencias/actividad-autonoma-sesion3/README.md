# Evidencias de la actividad autónoma - Sesión 3

Las cinco capturas obligatorias se obtienen de la aplicación Android ejecutándose en el emulador:

1. `01_formulario_limpio.png`: formulario inicial sin errores.
2. `02_nombre_vacio.png`: nombre obligatorio.
3. `03_precio_invalido.png`: precio no numérico.
4. `04_stock_invalido.png`: stock no entero.
5. `05_registro_correcto.png`: confirmación y campos limpios después del registro.

La lógica también está cubierta por siete pruebas automatizadas en `ProductoScreenTest.kt`.
